# Dataset

This folder contains the datasets used in the Cafe Sales Performance Analysis project.

## Files

- **dirty_cafe_sales.xlsx** – Original raw dataset before cleaning.
- **clean_cafe_sales_correct.xlsx** – Cleaned dataset after handling missing values, duplicates, formatting issues, and data validation.

## Dataset Information

- Records: 10,000
- Format: Microsoft Excel (.xlsx)
- Purpose: Data Cleaning, SQL Analysis, Python (Pandas) Analysis, and Power BI Dashboard
