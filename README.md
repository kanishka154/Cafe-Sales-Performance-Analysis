# ☕ Cafe Sales Performance Analysis

This project analyzes cafe sales data to uncover customer purchasing patterns, evaluate sales performance, and identify opportunities to increase revenue through data-driven business recommendations.

## Project Overview

This project follows the complete analytics workflow:

- Data Cleaning (Excel)
- SQL Analysis (MySQL)
- Data Analysis (Python & Pandas)
- Interactive Dashboard (Power BI)

## Tools Used

- Microsoft Excel
- MySQL
- Python
- Pandas
- NumPy
- Power BI
- Git & GitHub

## Dashboard

The Power BI dashboard includes:

- Sales KPIs
- Revenue Analysis
- Monthly Sales Trend
- Product Performance
- Payment Method Analysis
- Location-wise Revenue
- Revenue Ranking
