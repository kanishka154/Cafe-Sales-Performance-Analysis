# ☕ Cafe Sales Performance Analysis

An end-to-end Data Analytics project that analyzes cafe sales using **Excel, SQL, Python (Pandas), and Power BI**.

## Project Overview

This project follows the complete analytics workflow:

- Data Cleaning (Excel)
- SQL Analysis (MySQL)
- Data Analysis (Python & Pandas)
- Interactive Dashboard (Power BI)

## Tools Used

- Microsoft Excel
- MySQL
- Python
- Pandas
- NumPy
- Power BI
- Git & GitHub

## Dashboard

The Power BI dashboard includes:

- Sales KPIs
- Revenue Analysis
- Monthly Sales Trend
- Product Performance
- Payment Method Analysis
- Location-wise Revenue
- Revenue Ranking

*(Dashboard screenshot available in the PowerBI folder.)*
