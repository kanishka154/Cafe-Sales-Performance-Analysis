# Python

This folder contains the Python analysis for the Cafe Sales Performance Analysis project.

## Contents

- `cafe_sales_analysis.ipynb` – Jupyter Notebook containing data cleaning, exploratory data analysis (EDA), and visualizations.
- `requirements.txt` – List of Python libraries required to run the notebook.

## Libraries Used

- pandas
- numpy
- matplotlib
- seaborn

## Analysis Performed

- Data Loading
- Data Cleaning
- Missing Value Analysis
- Duplicate Detection
- Descriptive Statistics
- Revenue Analysis
- Product Analysis
- Payment Method Analysis
- Monthly Sales Trend
- Data Visualization
